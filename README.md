# My Ebook Library — Wattpad-style Details UI

Replace your GitHub Pages project files with:
- index.html
- manifest.json
- service-worker.js
- app-icon.svg

New features:
- Wattpad-inspired book details page
- custom cover image upload
- editable description/summary
- editable title, author, status, and tags
- chapter/parts list from EPUB TOC
- Continue Reading button
- saved reading progress
- backup/restore includes description, tags, status, and cover
- PWA/offline support
- persistent storage information

After uploading, commit and hard refresh once with Ctrl+Shift+R.
